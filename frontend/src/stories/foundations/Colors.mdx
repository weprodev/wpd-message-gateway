# Color foundations

Message Gateway uses **semantic tokens** as CSS variables (`hsl()` without the wrapper in variables). Components read `hsl(var(--token))` so one codebase supports **light** (default `:root`) and **dark** (`.dark` on an ancestor—typically `document.documentElement` or a layout shell).

Design intent:

- **Brand:** vivid indigo / purple primary for actions, focus ring, and logo-adjacent accents.
- **Light mode:** off-white surfaces, slate text hierarchy, soft semantic tints for badges.
- **Dark mode:** deep navy shell (`--background`), elevated cards (`--card`), muted blue-gray text, pill-style status colors with paired foregrounds.

## Implementation

- Toggle `dark` on the document or layout root to switch themes; components keep using the same token names.
- Use paired `*-foreground` tokens for text/icons on semantic fills.
- Token values: `src/index.css` (`:root` and `.dark`).
