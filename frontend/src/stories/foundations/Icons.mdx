# Iconography

We use **Material Symbols Outlined** as our primary iconography set. The system relies on semantic tokens, meaning icons automatically adapt their colors based on their parent context (`currentColor`) unless heavily overridden.

<a href="https://fonts.google.com/icons?icon.set=Material+Symbols&icon.style=Outlined" target="_blank" rel="noopener noreferrer" className="text-primary hover:underline font-medium">Browse the full Google Fonts Icon Catalog &rarr;</a>

## Usage & API

The `<Icon />` component is a lightweight wrapper that handles size scaling, accessibility (`aria-label`), and exact ligature alignments.

```tsx
import { Icon } from '@/components/ui/icon';

// Basic Usage
<Icon name="mail" />

// Sizing & Theming
<Icon name="settings" size="sm" className="text-muted-foreground" />

// Accessible Icon-Only Buttons
<button aria-label="Delete item">
  <Icon name="delete" />
</button>
```

### Props

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **`name`** | `string` | — | Exact ligature string from the Material Symbols catalog (e.g. `mark_email_unread`). |
| **`size`** | `'sm' \| 'md' \| 'lg'` | `'md'` | Defined scaling increments. `sm`: 18px, `md`: 24px, `lg`: 28px. |
| **`aria-label`** | `string` | — | Essential for icon-only components to support screen readers. |
| **`className`** | `string` | — | Standard `className` injection for margin padding or contextual color classes. |

## Sizing Scale

To maintain proportional alignment across layout densities, avoid arbitrary pixel sizing and strictly utilize the mapped sizing configurations.
